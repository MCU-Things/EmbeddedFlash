### 第4页：状态转换图
**内容要求：**
- [ ] 扇区状态转换：FREE → USING → FULL
- [ ] 扇区角色转换：UNASSIGNED → DATA/GC → DATA_GCING
- [ ] KV记录状态转换：UNUSED → PRE_WRITE → WRITE → PRE_DELETE → DELETED
- [ ] 转换条件和触发时机
- [ ] 异常状态处理

**状态转换表：**
| 当前状态 | 目标状态 | 触发条件 | 操作 |
|---------|---------|---------|------|
| FREE | USING | 分配扇区 | 更新状态表 |
| USING | FULL | 空间不足 | 标记为满 |
| UNUSED | PRE_WRITE | 开始写入 | 设置预写入标志 |

### 第5页：数据流图
**内容要求：**
- [ ] 写入流程：数据验证 → 状态更新 → 记录写入 → CRC计算
- [ ] 读取流程：状态查询 → 记录读取 → CRC验证 → 数据返回
- [ ] GC流程：空间检测 → 数据迁移 → 状态更新 → 空间回收
- [ ] 错误处理流程：错误检测 → 分类处理 → 恢复机制

**关键流程：**
```
写入：数据 → 验证 → 状态表更新 → 记录写入 → CRC校验 → 完成
读取：状态查询 → 记录读取 → CRC验证 → 数据返回
GC：  空间检测 → 选择源扇区 → 数据迁移 → 状态更新 → 擦除源扇区
```

## 设计规范要求

### 1. 图形规范
- **颜色编码**：统一使用颜色表示不同状态
- **字体大小**：标题12px，正文7px，注释5px
- **对齐方式**：所有元素严格对齐
- **比例关系**：保持合理的比例关系

### 2. 标注规范
- **地址标注**：使用十六进制格式（0x0801E000）
- **尺寸标注**：使用字节单位（32 Byte）
- **状态标注**：使用枚举值（EFLASH_SECTOR_STATUS_FREE=0）
